# Feature package

`knowde.feature` は、機能をドメインモデル、ユースケース、DB 操作、API、テストごと
まとめて配置するためのパッケージです。機能を削除するとき、そのディレクトリを
取り除けば大部分が消える構成を目指します。

## 配置の基準

- 各機能の `domain` はドメインモデルを持ち、DB 操作を含めません。
- DB や外部システムへのアクセスは各機能の `repo` に置きます。
- テストは対象コードと同じ機能ディレクトリに置きます。
- 複数機能を組み合わせる処理も、それを提供する機能側に置きます。
- `primitive` は機能固有の意味を持たない、依存の土台だけを置きます。
  他の feature パッケージには依存させません。
- 知識グラフ固有の型や変換処理は `knowde/graph` に置きます。

旧 `knowde.integration` と `knowde.shared` は使用しません。共有が必要になった処理も、
まず所有する機能を決め、真に機能非依存なものだけを `primitive` に置きます。
